# **App Name**: AgriStock Tracker

## Core Features:

- Registro de Productos de Alimentos: Permite registrar y gestionar diferentes tipos de alimentos para animales, especificando su nombre, descripción y tipo de animal al que se destina.
- Gestión de Unidades de Medida: Configura unidades de medida para el inventario (libras, kilos, bultos) y permite definir factores de conversión entre ellas para cálculos automáticos.
- Control de Inventario: Registra las entradas y salidas de stock, actualizando las cantidades disponibles en tiempo real, incluyendo la fecha y el movimiento.
- Registro de Ventas Simplificado: Permite registrar ventas rápidas de productos del inventario, deduciendo automáticamente las cantidades vendidas.
- Informes de Stock Actual: Genera una vista simple del inventario actual, mostrando la cantidad disponible de cada producto en su unidad de medida principal.
- Clasificación Inteligente de Alimentos: Utiliza un tool de IA para sugerir categorizaciones y nombres estandarizados para nuevos alimentos basándose en sus características, optimizando la organización del inventario.

## Style Guidelines:

- Esquema de color claro. Color primario (para encabezados y elementos interactivos): Un verde terroso y suave (#8BA34C).
- Color de fondo: Un crema-verde muy sutil y desaturado (#F6F8ED), para una base limpia y relajante.
- Color de acento (para resaltes o acciones importantes): Un dorado suave y cálido (#D0AC55), que complementa los tonos verdes de la naturaleza.
- Fuente principal: 'PT Sans' (sans-serif) para asegurar una alta legibilidad tanto en títulos como en el cuerpo de texto, aportando un toque moderno y amable.
- Uso de iconos funcionales y de línea simple para facilitar la navegación y la comprensión de las acciones clave (añadir, editar, vender, informes).
- Diseño limpio y estructurado con un énfasis en la organización de los datos, utilizando tarjetas o tablas claras para mostrar la información del inventario.
- Animaciones sutiles para feedback visual al guardar datos o navegar, mejorando la experiencia del usuario sin distraer.
